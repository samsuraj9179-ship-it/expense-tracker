# 💰 Expense Tracker

A streamlined Python application designed to help you track, categorize, and manage your daily expenses efficiently.

## 🚀 Features
* **Expense Logging:** Quickly add new transactions with amounts, categories, and dates.
* **Data Management:** Securely store and retrieve your financial records.
* **Insights & Summaries:** Get a clear overview of your spending habits.

## 🛠️ Technologies Used
* **Python** (Main application logic via `main.py`)
* **Dependencies:** Managed via `requirements.txt`
